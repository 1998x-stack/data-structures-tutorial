# 课程门户与文章设计系统

## 设计目标
构建可持续维护的长文教程，而非单纯的卡片陈列。布局服务于三种阅读任务：从首页寻找章节、从章内定位机制、通过图示和代码验证判断。

## 分工与文件所有权
| 文件 | 职责 | 编辑限制 |
| --- | --- | --- |
| `assets/css/site.css` | 首页、模块、导航、搜索框、卡片 | 不要直接影响章节正文 |
| `assets/css/article.css` | 章节阅读列、图注、表格、代码、公式和实验卡片 | 不要把正文需要的样式复制回每个 HTML |
| `assets/js/home.js` | 目录关键词筛选 | 必须在 JS 禁用时保留 28 个静态课程链接 |
| `assets/js/interactive.js` | 三类概念实验 | 交互是渐进增强；默认文字和图示不依赖运行 |
| `assets/svg/` | 独立教学矢量图 | 不依赖外部字体或第三方在线素材 |
| `courses.json` | 课程数据源 | 导航与元数据保持同步 |

## 视觉语义
- 阅读底色 `#fffdf9`；正文 `#203035`；注释 `#53676d`。
- 青绿 `#147f80`：直接数据流、可操作区域和高亮目标。
- 陶土色 `#c96e4f`：代价、警戒、重新分配或冲突。
- 紫色 `#7461ba`：节点关系、指针路径与次要结构。
- 颜色不单独承担含义，图示附文字标签和图注；注意满足背景/文字对比。
- 首页最大容器约 1190px，章内正文最大 850px，固定页脚、广告弹层和沉浸式自动滚动均不采用。

## 响应与可访问性
- 1440px：主列 + 吸顶目录；768px：目录改为文首导航；390/360px：正文独列，保留 16px 以上边距。
- 单幅图内部允许水平滚动，不能依靠全局 `overflow-x:hidden` 掩盖问题。
- 所有 `<svg>` 包含 `viewBox`、`title`、`desc`，图片有替代文本和解释性图注。
- 所有实验控件具备 `label`、键盘焦点与 `aria-live`；必须有静态初值。
- 打印时移除非必要导航和交互按钮，保留正文和关键图。
- 自动验收证据由 GitHub Actions 的 `browser-qa` artifact 记录，不要把未跑的截图声称为通过。

## 持续维护
新增/重构章节遵循 `AGENTS.md` 的逐页自足与正确性优先原则。遵从 [Olah-style-posts](https://github.com/1998x-stack/Olah-style-posts/tree/main/skills/olah-style-paper-posts) 的叙事、SVG、MathML 和 QA 路线，但图文均独立创作。
